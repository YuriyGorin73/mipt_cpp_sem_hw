# ФизКат

Консольная программа для учёта транспорта и вещей на балансе. Используется C++17.

## Сборка и запуск

В папке с файлами проекта выполнить:

```bash
g++ -std=c++17 -Wall -Wextra -Wpedantic main.cpp -o fizkat
./fizkat
```

В Windows после сборки запустить `fizkat.exe`.

Название и инвентарный номер вводятся одним словом.

## Команды

- `add scooter id name energy level` — электросамокат.
- `add bike id name level` — обычный велосипед.
- `add ebike id name energy level` — электровелосипед.
- `add helmet id name` — шлем.
- `add dock id name energy` — док-станция.
- `add cargo_bike id name energy level` — грузовой электровелосипед.
- `list` — все позиции по инвентарному номеру.
- `novice` — прокатная техника с уровнем не ниже 6.
- `energy` — суммарное суточное энергопотребление.
- `report` — количество позиций и суммарная энергия.
- `max_energy` — позиция с самым большим расходом энергии.
- `focus id` — поставить позицию на витрину.
- `show_focus` — показать позицию на витрине.
- `remove id` — удалить позицию.
- `info id` — вывести описание позиции.
- `ids` — вывести все инвентарные номера.
- `quit` — выход.

## Классы

- `InventoryItem` — общий абстрактный базовый класс.
- `EnergyConsumer` — абстрактный класс для объектов с расходом энергии.
- `Transport` — базовый класс транспорта.
- `ElectricScooter`, `Bicycle`, `ElectricBike`, `CargoBike` — виды транспорта.
- `Helmet` и `DockStation` — вещи на балансе.
- `Fleet` — хранит объекты и выполняет команды.
- `ServiceCenter` — проводит техосмотр.
- `Registry<T, Capacity>` — шаблонный журнал инвентарных номеров.

Схема наследования:

```text
InventoryItem
├── Transport
│   ├── ElectricScooter ── EnergyConsumer
│   ├── Bicycle
│   ├── ElectricBike ──── EnergyConsumer
│   └── CargoBike ─────── EnergyConsumer
├── Helmet
└── DockStation ───────── EnergyConsumer
```

`ElectricScooter`, `ElectricBike`, `CargoBike` и `DockStation` используют множественное наследование.

## Что используется в программе

- `unique_ptr` хранит позиции парка. Парк сам удаляет объекты.
- `shared_ptr` хранит общие описания моделей транспорта.
- `weak_ptr` используется для витрины. После удаления позиции витрина показывает `removed`. Пока фокус ещё не был установлен, выводится `no focus`.
- `operator<<` печатает инвентарный номер и имя. `operator<` сравнивает позиции по инвентарному номеру.
- `Registry` хранит номера. Для `Registry<string, 100>` сделана специализация `add`, которая не добавляет повторный номер.
- `FleetError` — общий класс исключений. `InspectionError` возникает, если в имени транспорта есть `broken`. `CommandError` используется при неправильной команде или аргументах.

Транспорт добавляется в парк только после техосмотра. При отказе состояние парка не меняется.
